# ETL-обработка данных и дашборд в Yandex DataLens

## Описание задачи
Полный цикл подготовки данных (ETL) в Loginom и построение интерактивного дашборда в Yandex DataLens для анализа продаж.

## Стек
Loginom, Yandex DataLens, SQL (SQLite).

## Что сделано
1. Загружены данные из CSV, Excel и базы данных SQLite.
2. Проведена очистка данных: устранены дубликаты, обработаны выбросы (метод стандартного отклонения), восстановлены пропуски (через медианную наценку).
3. Созданы новые аналитические признаки (валовая прибыль, «редкие» товары, ABC-анализ).
4. Построен интерактивный дашборд в DataLens: динамика выручки, маржинальность, география продаж, селекторы по датам и городам.
